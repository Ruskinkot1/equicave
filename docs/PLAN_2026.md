# EquiCave plan: a self-contained equivariant multi-task pocket model (one-month plan, from 2026-10-03)

Three outputs from one structure and one model, with no P2Rank, fpocket or Java anywhere in `src/` or `training/`:
(A) ranked binding sites, (B) multi-label pocket property classes, (C) a ligand-atom hotspot field inside each pocket.
Everything measured in this repository is reported with its protocol; nothing from an unconverged run goes into a table.

## Claims (falsifiable) and what kills them
| id | claim | killed if |
|---|---|---|
| C1 | native candidates + learned ranker match or beat fpocket+P2Rank+ranker without any external tool | CI of the difference in top-1 or top-(N+2) is below 0 |
| C2 | network features raise ranker top-1 and top-(N+2) | paired CI includes 0 |
| C3 | degree-2 tensor channels beat degree<=1 and the invariant model at equal depth/width | full - no_tensors CI includes 0 |
| C4 | cavity probes beat sphere probes / no probes | full - no_probes CI includes 0 |
| C5 | property classes and the hotspot field beat geometry-only baselines on held-out clusters | no gain in AUROC/AP or enrichment |

## Architecture (see docs/ARCHITECTURE.md for the full specification)
1. Native candidates: 1 A lattice, 26-ray closure, connected cavities, peak splitting (NMS 6 A), two depth tiers, <= 30 per structure.
2. EquiCave-Net: residue nodes (CA, ESM-2), cavity-probe nodes on free lattice points, SAS surface nodes; every node carries
   scalar, vector and symmetric-traceless tensor channels; geometric tensor attention with gated degree-0/1/2 messages;
   pseudo-scalar triple products for chirality; 4-5 layers; heads for residue/probe segmentation (Dice+BCE), centre offsets
   (equivariant read-out, set loss) + confidence, multi-label properties (pooled probes), hotspot classes (focal BCE).
3. Hybrid ranking: native + geometry + chemistry + network features -> LambdaRank; isotonic calibration.

## Data and honesty rules
RCSB (CC0) only for the shipped model; third-party sets never committed; held-out families never used for selection;
split by 30 % cluster; external sets filtered for train similarity; >= 3 seeds; paired cluster bootstrap; Holm correction;
"not run" written where a number is missing.

## Risks
GPU availability (the network cannot be trained to convergence on 4 CPU cores); label noise from CCD heuristics;
ESM-2 650M memory on long chains; HOLO4K domain shift (multimers); LIGYSIS chain lists are pandas pickles (parsed with a
restricted unpickler); CryptoBench access path.
